# IGASpeedometer

Using an Interactive Genetic Algorithm (IGA) to generate a speedometer in Processing.

## Overview
This project explores generative design through an Interactive Genetic Algorithm. Instead of manually designing a speedometer, the program creates multiple candidate designs and lets the user choose which ones are most visually appealing. The selected candidates are then used to generate the next set of speedometer variations.

## What this project does
- Generates multiple speedometer designs automatically
- Uses user feedback to guide evolution
- Evolves designs across generations to improve their appearance
- Runs as a Processing sketch

## Requirements
- Processing 3.x or later
- A Java-enabled environment supported by Processing

## How to run
1. Open the project in the Processing IDE.
2. Make sure all necessary sketch files are present in the same folder.
3. Click the Run button to start the program.
4. Select the designs you prefer to guide the genetic algorithm.

## How it works
- A population of speedometer candidates is created.
- Each candidate is evaluated subjectively by the user.
- The best-performing designs are selected.
- New generations are created using variation and selection, simulating evolutionary optimization.

## Purpose
The goal is to demonstrate how interactive evolutionary computation can be used for creative visual design, specifically in generating speedometer interfaces and layouts.
